# Shared policies

Portable payload, separate from root AGENTS.md; nothing is automatically installed.

- [Evidence](evidence.md): match completion claims to observed results.
- [Behavioral tests](behavioral-tests.md): test contracts rather than internals.
- [Architecture](architecture.md): keep code findable, responsibilities clear, and changes verifiable with three minimum principles.
- [Security](security.md): protect credentials and review consequential changes.
- [Logging](logging.md): use consistent levels and structured events; remove task-owned temporary debug probes.
- [Issue workflow](issue-workflow.md): decide when to create, update, comment, hand off and close issues; preserve requirements, history and publication safety.
- [PR workflow](pr-workflow.md): plan coherent merge units, distinguish task and PR dependencies, and preserve candidate evidence and history authority.
- [Visual documentation](visual-documentation.md): maintain diagram sources and screenshot manuals.

Source attribution and adaptation notes live with each policy. Preserve destination
instructions and existing authorization when selecting shared rules.
