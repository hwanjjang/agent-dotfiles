# Visual documentation

Scope: producing diagrams or user manuals, and applicable SDLC documentation work.

- Keep an editable diagram source alongside its delivered artifact. Use the included
  Archify skill for architecture, workflow, sequence, data-flow, and lifecycle views.
  Report automated validation separately from actual visual inspection.
- A screenshot-based user manual includes the user's goal, prerequisites, ordered
  actions, expected outcomes, and screenshots of the relevant actual product states.
- Deliver the manual as a PDF with editable source and reusable sanitized images.
  Use screenshot-manual to generate and render it, then inspect every rendered page
  for readable images, correct captions, pagination, clipping, and missing glyphs.
- State the product revision and scenarios actually exercised. Do not infer a working
  action from a screenshot alone. Update affected manuals when their documented flow changes.
- Keep raw captures and draft output local. Publish only reviewed, sanitized artifacts
  within the task's authority. Ordinary unrelated edits need no invented diagram or manual.
